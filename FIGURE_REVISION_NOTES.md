## Numerical and methodological scope

This revision changes presentation, not the analyses. The original data file, all
six result CSVs, six simulation/estimation/validation scripts, two protocol/reporting
materials and LICENSE are unchanged. The 11 original Figure 3 data series are
retained: three in A, six in B and two in C. The equivalence/power and SESOI reference
lines are retained. Panel C uses the original 150-replication grid at n = 300.

Two small plotting safeguards were added: a valid TRC grid is used even when the
shorter validation CSV is absent, and the fallback validation run is restricted to
n = 300 rather than pooling sample sizes under an n = 300 label. Missing or malformed
inputs now produce an explicit error instead of silently omitting panels/series.
Neither safeguard changes the plotted values for the supplied results.

The main README reproduction sequence now includes the already-documented
150-replication TRC-grid command before figure generation, so a full reproduction
does not accidentally reuse the bundled TRC grid.

The revised plotting script is the only modified original code file. `pypdf` is the
one additional dependency, for vector-PDF panel assembly. The other source files
and result files are preserved, not regenerated by this revision.

## Checks performed

The revision check report is in `qa/figure_revision_checks.json`. The figures were
regenerated from the stored results, their PDFs were rendered and visually checked,
and raster resolution/compression and original-file integrity were checked. The full
plotting script was also smoke-tested on a fresh copy. This is **not** a rerun of the
full Python/R simulation and estimation pipeline; that independent numerical
reproduction remains the separate task described in the original handover.

Text-boundary and legend-position checks do not prove the absence of every possible
visual issue. Visual review of the rendered figures complements those checks.
Naturally coincident data curves remain at their true coordinates; they have not
been moved to manufacture separation.

## Manuscript placement and caption check

The manuscript was not included in the supplied archives, so no manuscript file or
caption has been edited. Insert the revised Figures 1–3 at 170 mm width to preserve
the intended text size. Figure 3 needs more vertical space than the original.

Check its existing caption for references to “left/middle/right” panels or coloured
curves. A, B and C now run **top to bottom**, and curve identities should refer to the
legend labels, line patterns and marker symbols rather than colours. The panel
labels, estimands and numerical results are unchanged. The participant SD = 1.6
legend entry denotes the original sigma_u sensitivity condition; the item-effect
SD = 0.3 entries denote the original sigma_slope condition, both on the logit scale.
